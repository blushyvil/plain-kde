## HOW TO INSTALL THIS DOTFILES

<div>
  
1. install the git first with<br>
```sudo pacman -S git```<br>
2. clone this repo into ~/dotfiles<br>
```git clone https://github.com/blushyvil/plain-kde.git ~/dotfiles```<br>
3. run the script install.sh<br>
```cd ~/dotfiles```<br>
```sudo ./.install.sh```
and there you go~!<br>
